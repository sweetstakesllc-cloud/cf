# Storefront size finder

Published September 8, 2026 to MAIN theme 188182659400 (CF Staging). The main-product section renders `cf-size-finder` before buy buttons on clothing pages. Clothing classification uses Shopify taxonomy ancestor aa-1, with title/type fallback for uncategorized products. Bags, shoes and accessories are excluded.

The helper runs entirely in the browser. It collects height/weight, adult sizing reference, preferred fit, optional usual letter size and optional flat reference-garment measurements. It does not store or transmit these inputs. No AI service, API key, subscription or trained fit model is used.

Height/weight output is a broad, uncalibrated merchant heuristic (weight normalized to 175 cm with different adult reference bands), not a statistical prediction or brand size chart. It intentionally reports a range and explains its limitations. Do not market this as validated AI sizing. It needs calibration against actual fit outcomes before stronger accuracy claims are appropriate. Usual-size input is only a consistency cross-check: it never overrides or shifts the independent height/weight estimate. A disagreement prompts a garment measurement comparison. Reference garment chest width supersedes letter-size matching when a valid listing measurement is available. The 2 cm closeness threshold is a width comparison, not a full-fit guarantee.

Seller `Fits XL` etc. notes take priority over the label only for single-size products. Numeric sizes are not converted. The UI distinguishes available sizes from the suggested range and identifies sold-out listings. Product-level measurements are not assigned to different size variants. Tops may compare custom.pit, custom.chest / 2, and custom.length. Bottoms and specialist cuts ask for appropriate measurements rather than generating a height/weight size. Children's sizing is unsupported and clearly identified.

This feature never selects a variant or modifies the cart. Native dialog supports keyboard dismissal, focus containment/restoration and a live result. The trigger stays hidden until JavaScript initializes. Dynamic section replacements initialize through a custom element; duplicate script loading is guarded.

Validation: `node web/theme/tests/size-finder.cjs` (focused checks, including usual-size independence and sensitivity to height, weight and garment measurements). Headless Chrome checks passed on the live Palm Angels Bear T-shirt page at desktop and 390px mobile: submit, comparison, Escape, restored focus, no horizontal overflow.
